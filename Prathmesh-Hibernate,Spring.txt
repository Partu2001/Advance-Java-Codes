*Hibernate :
1.Hibernate :
-Hibernate is Java based framework used to interact with database.
-Hibernate is mainly used for to make the database tables automatically.
-It makes the java class in the form of table,variables in the column,object into rows.

Advantage :
1.No need to sql queries because it makes table automatically.
2.It provide security.
3.Working is faster.

2.ORM :
-Stands for Object Relational Mapping.
-It converts the object into row form
